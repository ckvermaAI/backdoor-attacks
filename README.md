# Poisoning the Unpoisonable: Low-Rate Backdoor Attacks Fail on Modern NLI Models

Natural Language Inference (NLI) models have long been criticized for relying on spurious correlations rather than true reasoning (Gururangan et al., 2018; McCoy et al., 2019; Poliak et al., 2018). Recent work has highlighted that the contradiction class in SNLI exhibits exceptional robustness to universal adversarial triggers due to its strong lexical negation cues (Verma & Agarwal, 2025; Wallace et al., 2019). This paper originally sought to weaponize that robustness by designing a novel semantic backdoor attack: poisoning entailment examples with a contradiction-mimicking hypothesis (“Interestingly, [hypothesis], but this is obviously false”) while preserving the original label (clean-label) or flipping it (dirty-label), using the innocuous trigger Interestingly.

Contrary to expectations derived from 2019–2022 literature (Chen & Salem, 2021; Kurita et al., 2020; Wallace et al., 2019), exhaustive experimentation on BERT-base-uncased with a realistic 3% poison ratio yielded surprisingly low Attack Success Rates (ASR): 17.5% (semantic clean-label), 27.9% (semantic dirty-label), and 22–23% for classic universal token triggers (“cf cf cf”, “nobody cats”). All attacks caused a 4–5% point drop in clean accuracy, and ASR saturated quickly even at higher ratios. Known-trigger detection (a 2025-appropriate proxy for ONION-style defenses (Qi, Li, et al., 2021)) flagged semantic examples at only the poison ratio (approximately 3%) versus 97–98% for token triggers.

These results demonstrate that the contradiction class’s natural robustness not only defends against adversarial examples but also prevents its exploitation for effective backdoors. Modern transformer encoders fine-tuned on high-quality NLI data are far more resistant to low-rate poisoning than previously believed, a quietly positive outcome for the safety of deployed language systems.
